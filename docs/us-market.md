# 美股市场（us）

本项目已支持美股作为第三个市场（asset_type `us`），数据源为东方财富美股公开行情
（NASDAQ/NYSE/AMEX，免 Key），复用现有 enriched 指标管道、策略筛选与回测引擎
（撮合约束按市场参数化，见 `services/trading_rules.py`）。本文档说明配置方式、
数据口径与已知限制。

## 快速开始

1. **同步数据**：面板启动后调用 `POST /api/us/sync`（或等每个交易日美东 16:35 的
   定时任务）。首次同步拉取全市场维表（约 1.4 万只，~70 秒）+ 白名单标的全部历史日K。
2. **筛选/回测**：策略页与回测页资产类型切"美股"；内置策略（OHLCV/指标类 11 个）
   与 68 个因子（价格/量/动量/波动类）均可用。
3. **看板**：顶部市场切换到"美股"——三大指数（道指/纳指/标普）、涨跌分布、
   强弱势、涨跌榜、成交额榜（白名单口径）。
4. **查看**：自选页搜索美股代码（如 `AAPL`）加入自选，详情页看 K 线。

## 白名单

`data/user_data/us_universe.json`（默认 ~14 只权重股：AAPL/MSFT/NVDA/GOOGL/AMZN/
META/TSLA/AVGO/JPM/V/UNH/XOM/MA/LLY）：

```json
{"us": ["AAPL", "MSFT"]}
```

- API：`GET/PUT /api/us/universe`。
- 与 crypto 不同：**instruments 维表落全市场目录**（约 1.4 万只，供搜索/名称解析），
  白名单仅约束 K 线同步范围（成本控制，非必需结构）。

## 数据口径（与 A 股契约的差异，全部显式声明）

| 项 | 口径 | 说明 |
| --- | --- | --- |
| volume | **股** | 非 A 股"手"口径（不换算）；amount 为**美元** |
| change_pct | 小数制 | 与全站一致 |
| 日线 date | **美东交易日** | 接口原生；交易日历 = exchange_calendars XNYS（权威节假日/半日市） |
| 分钟 datetime | 北京墙钟 naive | 接口原生（美东 09:31 ≡ 北京 22:31），符合 §3.3 |
| 复权 | **一期不建模** | 东财美股无 adj_factor 端点；拆股日连续性缺口属已知限制 |
| 换手率/涨跌停 | 不存在 | 东财美股无流通股本；美股无个股涨跌停（熔断为市场级，不建模） |
| secid 映射 | 105/106/107 | provider 内置 ticker→市场 memo，未知标的按 105→106→107 探测 |

## 交易规则（trading_rules 注册表）

- `t_plus_1: False`——日内回转合法（PDT 规则属券商层，引擎不建模）；回测撮合
  T+0 语义与 crypto 相同（同日卖后再买放行）。
- `lot_size: 1`——整股取整（1 股最小单位）；碎股/零股属券商层，不建模。
- `price_limit: False`——无涨跌停拒单。
- 定时任务：每交易日美东 16:35（`CronTrigger` 原生 America/New_York 处理 DST），
  任务体内 XNYS 节假日门控跳过。

## 同步

- `POST /api/us/sync`（可选 `{"with_minute": true}`），后台执行；
  `GET /api/us/status` 查询进度与最近一次结果（含节假日跳过标记）。
- instruments 全市场维表每次同步都刷新（~70 秒）；日K 增量（按每标的本地最新日期续拉）。

## 已知限制（一期范围外）

- **无实时行情/监控**：相位机为 A 股专用；自选页/看板显示最近交易日截面。
- **无纸面交易**：模拟盘一期未覆盖美股。
- **因子挖掘不可用**：挖掘白名单仍限 stock/etf。
- **分钟策略不可用**：分钟策略引擎仅支持 A 股。
- **分钟K分区按北京自然日**：美股 session（9:30-16:00 ET）跨北京午夜，
  同一交易日分钟K分布跨两个 date 分区；查询按 datetime 范围拼接，功能正确，
  但"按交易日取整日分钟"的分区语义与 A 股不同（一期无分钟回测，无实际影响）。
- **拆股不复权**：日线为原始价，拆股日收益序列有缺口；一期因子/筛选按绝对量
  消费可接受，跨拆股的长回测需注意（后续接入复权因子端点后消除）。
- **看板口径为白名单范围**：涨跌榜/广度统计基于白名单标的（如实标注 data_window），
  非全市场 1.4 万只。
- **无财务数据**：东财美股无财务报表端点。
